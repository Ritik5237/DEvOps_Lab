EXPERIMENT 5 — Docker Management
Observation:

EXPERIMENT 6 — Docker Storage
Observation:
Data stored in the container writable layer was lost after container deletion. Data stored in a named Docker volume and bind mount remained persistent after deleting the container.

EXPERIMENT 7 — Docker Network
Observation:
Two Docker containers successfully communicated through a user-defined Docker network. Communication was verified using both the container name and container IP address.

EXPERIMENT 8 — Kubernetes Continuous Deployment
Observation:
The application was deployed to a Kubernetes cluster using Deployment and Service manifests. Jenkins automated the deployment process by applying the Kubernetes manifests through the CI/CD pipeline.
